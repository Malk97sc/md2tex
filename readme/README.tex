\subsection*{md2tex}
\addcontentsline{toc}{subsection}{md2tex}

\texttt{md2tex} is a powerful, customizable open-source converter that safely translates your standard and GitHub Flavored Markdown (GFM) logic into pure TeX syntax. 

Originally built as a simple parser, \texttt{md2tex} has been \textbf{completely modernized} into a robust parsing pipeline powered by an Intermediate Representation (IR) AST structure that guarantees 100\% stable parsing without colliding formatting conflicts.

\subsection*{Features}
\addcontentsline{toc}{subsection}{Features}

\begin{itemize}
    \item \textbf{Strict AST Architecture}: Guaranteed reliable markdown block parsing before inline TeX escaping prevents artifacts.
    \item \textbf{TUI Dashboard}: Native Textual Terminal User Interface for configuration-free execution.
    \item \textbf{Full Template Control}: Automatically wrap logic in predefined headers, or inject converted contents seamlessly into custom TeX template \texttt{@@BODYTOKEN@@} blocks.
    \item \textbf{GFM Support}: Full implicit translation of \texttt{Tables}, \texttt{Strikethroughs}, Code Blocks, Headers, References from standard Markdowns directly into \texttt{tabular}, \texttt{sout}, \texttt{minted}, \texttt{section}, etc.
    \item \textbf{Quotes}: Native parameter translation into French inline formatting \texttt{\textbackslash\{\}enquote\{\}} via \texttt{csquotes}.
\end{itemize}

\subsection*{Installation}
\addcontentsline{toc}{subsection}{Installation}

It is highly recommended to manage implementations via modern package tooling \href{https://docs.astral.sh/uv/\#highlights}{uv}.

\subsubsection*{1. Simple installation}
\addcontentsline{toc}{subsubsection}{1. Simple installation}

\begin{lstlisting}
git clone git@github.com:Malk97sc/md2tex.git
cd md2tex

# We strongly recommend using the interactive TUI
pip install ".[tui]"
\end{lstlisting}

\subsubsection*{2. Developing}
\addcontentsline{toc}{subsubsection}{2. Developing}

\begin{lstlisting}
git clone git@github.com:Malk97sc/md2tex.git
cd md2tex

# Setup tests and developer linting suites
uv sync
\end{lstlisting}

\subsubsection*{3. LaTeX Requirements}
\addcontentsline{toc}{subsubsection}{3. LaTeX Requirements}

For local PDF compilation of your \texttt{.tex} files, you need \texttt{pdflatex} installed. On Unix systems, you can install TeX Live:

\noindent{}\textbf{Ubuntu / Debian / Mint:}

\begin{lstlisting}
sudo apt update
sudo apt install texlive-latex-extra texlive-fonts-recommended
\end{lstlisting}

\noindent{}\textbf{Fedora / RHEL:}

\begin{lstlisting}
sudo dnf install texlive-scheme-medium
\end{lstlisting}

\noindent{}\textbf{macOS (via Homebrew):}

\begin{lstlisting}
brew install --cask mactex-no-gui
\end{lstlisting}

\subsection*{Usage}
\addcontentsline{toc}{subsection}{Usage}

\subsubsection*{Place your documents}
\addcontentsline{toc}{subsubsection}{Place your documents}

To use md2tex, we recommend placing your \texttt{.md} files inside the \href{/myfiles/}{myfiles} folder.

\subsubsection*{Terminal Interface (TUI) Mode - Recommended}
\addcontentsline{toc}{subsubsection}{Terminal Interface (TUI) Mode - Recommended}

Instead of memorizing flags, directly launch a beautiful TUI configuration dashboard:

\begin{lstlisting}
md2tex tui

# Or
md2tex interactive
\end{lstlisting}

The TUI can now convert to \texttt{.tex} and optionally compile to \texttt{.pdf} with \texttt{pdflatex} (2 passes), including an explicit \texttt{shell-escape} toggle.

\subsubsection*{Direct CLI Conversion}
\addcontentsline{toc}{subsubsection}{Direct CLI Conversion}

If you're looking for headless automations or quick CLI overrides:

\begin{lstlisting}
# General convert (Defaults Article class output to output/<filename>.tex)
md2tex myfiles/document.md
# Or
md2tex path/to/document.md

# Build full encapsulated `.tex` compiling with headers
md2tex path/to/document.md -c

# Advanced custom translation output
md2tex source.md -c -t ./utils/template.tex -o ./export/export.tex -d book -u -f
\end{lstlisting}
